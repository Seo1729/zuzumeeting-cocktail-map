Claude Code 세션은 기기 간에 옮겨지지 않습니다. 이 문서가 그 역할을 대신합니다.
새 컴퓨터에서 저장소를 클론한 뒤, Claude Code를 열고 **"docs/HANDOFF.md 읽고 이어서 진행해"**
라고 하면 됩니다.

## 2. 새 컴퓨터 세팅

```bash
git clone https://github.com/Seo1729/zuzumeeting-cocktail-map.git
cd zuzumeeting-cocktail-map
npm install
npm run dev
```

**Node.js 22.6 이상**이 필요합니다. `npm run validate`가 Node 내장 TypeScript 타입
스트리핑(`--experimental-strip-types`)을 쓰기 때문입니다. `node -v`로 확인하세요.

### git에 없어서 다시 만들어야 하는 것

| 파일 | 내용 | 없으면 |
|---|---|---|
| `.env.local` | `VITE_KAKAO_JS_KEY=...` | 지도 화면만 폴백 표시. 나머지는 정상 동작 |
| `node_modules/` | `npm install`로 생성 | — |
| `board-api/node_modules/` | `cd board-api && npm install` | 백엔드 연습 프로젝트를 볼 때만 필요 |

`.env.local`은 `.env.example`을 복사해서 만듭니다. 발급 절차는 `README.md` 4절에 있습니다.

### USB에서 직접 작업하는 것에 대해

이 프로젝트는 처음에 **FAT32 이동식 USB 드라이브**에서 만들어졌습니다.
USB를 그대로 꽂아서 이어 작업할 수도 있지만, 내장 드라이브에 클론하는 편을 권합니다.

| | USB에서 직접 | **내장 드라이브에 클론** |
|---|---|---|
| 속도 | 느림 | 빠름 |
| `npm install` | 이미 있으면 생략 가능 | 한 번 필요 (내장 드라이브면 금방) |
| git 설정 | `safe.directory` 예외 필요 | 불필요 |
| 위험 | 작업 중 USB 분리 시 손상 | 없음 |

느린 이유는 `node_modules`가 작은 파일 1만 2천여 개(약 160MB)인데
USB + FAT32 조합이 이런 작업에 특히 약하기 때문입니다.
`git init`이 "dubious ownership"으로 거부되는 것도 FAT32가 파일 소유권을
기록하지 않아서입니다(7절 참고).

USB 폴더를 통째로 복사하는 방법도 있지만, 그 1만 2천 개 파일을 USB에서
읽어내는 것이 클론 + `npm install`보다 오래 걸립니다.

### 두 대 이상에서 번갈아 작업할 때

**작업 시작 전에 `git pull`, 끝나면 `git push`.**

```bash
git pull      # 시작할 때
git push      # 끝낼 때
```

이걸 빠뜨리면 양쪽에서 각자 커밋이 쌓여 나중에 충돌을 풀어야 합니다.
USB 하나만 들고 다니면 저장소가 하나뿐이라 이 문제가 없는 대신 계속 느립니다 —
그게 USB 방식의 유일한 장점입니다.

**Claude Code 세션 자체는 기기 간에 옮겨지지 않습니다.** 폴더를 옮기든 클론하든
새 기기에서는 새 세션이고, 그래서 이 문서가 있습니다.

## 3. 현재 상태

### 완료 — 지시서의 7단계 전부

| 단계 | 내용 |
|---|---|
| 1 | Vite + React 19 + TS strict + Tailwind v4, HashRouter |
| 2 | Zod 스키마, `npm run validate`, 빌드 차단 |
| 3 | 리스트 화면 (필터·정렬·URL 쿼리 동기화) |
| 4 | 상세 화면 (운영진 코멘트 강조, 딥링크, 기준일 고지) |
| 5 | 지도 화면 (`src/map/` 격리, SDK 동적 로드, 폴백) |
| 6 | PWA (manifest, 아이콘, 서비스워커 precache) |
| 7 | README |

### 지시서 이후에 더 붙인 것

| 기능 | 어디 |
|---|---|
| **지도 실물 확인 완료** | 카카오 키를 꽂고 실제 타일·핀·바텀시트까지 눈으로 봤습니다 |
| **현재 위치 표시** | `src/pages/useUserLocation.ts`, 지도의 "내 위치" 버튼. 전주 밖이면 지도에 반영하지 않고 안내만 합니다(`isInJeonju`) |
| **바 검색** | 리스트 상단. 이름 · 태그 · 운영진 한 줄 평을 훑고 `?q=`로 URL에 들어갑니다 |
| **메뉴 검색** | 상세 화면. 이름 · 재료(`desc`) · 기주를 훑습니다. 메뉴 8개 미만이면 검색칸을 감춥니다 |

`npm run build`는 통과합니다. `any` 0건, `window.kakao` 참조는 `src/map/` 안에만.
`npm run lint`에 `KakaoMapView`의 ref 경고 1건이 남아 있는데, 렌더 중 ref에 최신
콜백을 담아두는 의도된 패턴입니다.

### 배포됨 — 실제 주소에서 동작합니다

```
https://zuzumeeting-cocktail-map.maple4357.workers.dev
```

**Pages가 아니라 Workers입니다.** Cloudflare가 둘을 합치면서 저장소를 연결해 만들면
Workers 쪽으로 생깁니다. 이 앱은 정적 파일뿐이라 동작 차이는 없고 설정 항목 이름만
다릅니다. `main`에 push하면 자동 재배포됩니다. 자세한 건 `README.md` 5절.

배포본에서 확인한 것: 리스트 · 지도(핀 11개) · 검색 · 서비스워커 · 환경변수(번들에
카카오 키가 박혀 있음) · 카카오 도메인 등록.

### ⚠️ 아직 실물로 확인 못 한 것

| 항목 | 어디까지 확인했나 | 왜 못 했나 |
|---|---|---|
| **iOS 홈 화면 추가** | manifest와 `apple-touch-icon` 태그만 확인 | 실기기 없음 |
| **실기기에서의 현재 위치** | 데스크톱 브라우저에서만 확인 | GPS가 없어 정확도 원의 실제 크기를 못 봄. 술집 지하에서 오차가 수백 m까지 날 수 있습니다 |
| **실제 오프라인 동작** | 배포본에서 서비스워커가 `activated`로 페이지를 제어하고, 앱 셸(`index.html`·JS·CSS)이 캐시에 들어간 것까지 확인 | 비행기 모드로 실제로 끊어보지는 않음 |

## 4. 절대 제약 — 새로 붙이기 전에 반드시 확인

`docs/SPEC.md`의 "절대 제약"입니다. **필요해 보여도 제안하지 말 것:**

- 백엔드 서버, DB, API 라우트 없음. 100% 정적 사이트
- 로그인/회원가입/인증 없음
- 리뷰·평점·댓글·좋아요 등 **쓰기 기능 없음. 읽기 전용**
- 결제수단이 필요한 서비스 금지 (Google Maps 등)
- Next.js / React Native / Electron 금지
- 상태관리 라이브러리(Redux, Zustand 등) 금지
- 테스트 프레임워크 금지 — 검증 스크립트 하나로 충분
- **실존하지 않는 가게 이름·주소·좌표를 지어내지 말 것.** 샘플은 `__SAMPLE__` 접두사

스택 변경 제안도 금지입니다. 새 라이브러리는 **먼저 물어보고 승인**을 받으세요.

## 5. 코드에서 지켜야 할 규칙 2가지

**1. `window.kakao` 참조는 `src/map/` 안에서만.**
`KakaoMapView`는 `markers` / `selectedId` / `onSelect` / `userLocation` 네 props만 받습니다.
다른 지도 서비스로 갈아탈 때 이 폴더만 통째로 바꾸기 위한 경계입니다.

> "전주 밖 좌표는 지도에 반영하지 않는다"는 판단은 **지도 안이 아니라 `MapPage`에** 있습니다.
> 전주라는 개념이 지도 레이어에 들어가면 그 폴더가 이 앱 전용이 되어버립니다.
> `isInJeonju`로 거른 뒤 `null`을 넘기고, 지도는 받은 좌표를 그릴 뿐입니다.

> 지시서 스케치의 `MapMarker.selected` 필드는 **일부러 뺐습니다.** 선택 상태를 마커
> 객체에 넣으면 핀 하나 고를 때마다 `markers` 배열 identity가 바뀌고, 마커 재생성
> 이펙트가 매번 돌면서 지도가 선택할 때마다 전체 영역으로 리셋됩니다.
> 이유는 `src/map/types.ts` 주석에 남겨뒀습니다.

**2. `src/domain/`에는 React를 import하지 않습니다.**
`selectors.ts`는 순수 함수만 둡니다. 화면이 바뀌어도 계산 로직은 그대로 쓸 수 있어야 합니다.

## 6. 다음 할 일 (우선순위)

배포는 끝났습니다. 이제 앱을 쓸모 있게 만드는 일만 남았습니다.

1. **빈 칸 채우기** ← 지금 가장 큰 일. 3절의 표를 보세요. 특히 `note`가 빈 6곳은
   이 앱의 존재 이유가 비어 있는 상태입니다. `npm run validate`가 바마다 경고로
   알려주므로 빠뜨린 곳을 찾을 수 있습니다
2. **부원 오픈채팅방에 링크 + "홈 화면에 추가" 안내** (문구는 `README.md` 6절).
   1번을 어느 정도 채운 뒤에 하는 편이 낫습니다 — 빈 카드만 보면 다시 안 옵니다
3. 신시가지 바 조사 — 상권 칩은 있는데 데이터가 0곳입니다
4. 실기기(아이폰·안드로이드)에서 홈 화면 추가와 현재 위치 확인. 3절 표에 남은 항목입니다

### 아직 만들지 말 것

**"지금 영업 중" 표시, 거리순 정렬.** 지시서에 없습니다.
**부원들이 며칠 실제로 써보고 나온 불만으로 정하는 게 맞습니다.**
지금 넣으면 안 쓸 기능을 만들 가능성이 큽니다.

> 검색도 원래 이 목록에 있었지만, 아람 메뉴가 33개가 되어 한 화면에 안 들어오게 되면서
> 만들었습니다. **"데이터가 없어서 뭐가 불편할지 모른다"가 근거였으므로, 그 조건이
> 사라진 기능은 만들어도 됩니다.** 반대로 위 두 개는 아직 그 조건이 그대로입니다.

### 검색을 더 밀어붙인다면

**바를 건너뛴 메뉴 검색** — "모히또 파는 데 어디야?"처럼 전체 바에서 칵테일을 찾는 것.
지금 메뉴 검색은 한 바 안에서만 됩니다. 앱 목적("뭘 시킬까")에는 맞지만,
**메뉴가 들어간 바가 4곳뿐이라 지금 만들면 결과가 거의 안 나옵니다.** 1번을 먼저 하세요.

## 7. 작업하며 실제로 부딪힌 함정들

| 함정 | 대응 |
|---|---|
| **커밋 전 검증을 안 해서 깨진 `bars.json`을 push한 적 있음** | 데이터 수정 후 반드시 `npm run validate`. 커밋 전 `npm run build`가 더 안전 |
| FAT32 USB 등 소유권을 기록하지 않는 드라이브에서 `git init`이 "dubious ownership"으로 거부 | `git config --global --add safe.directory '<경로>'`. 기기마다 한 번씩 필요 |
| Node 22.6 미만에서 `bad option: --experimental-strip-types` | Node 22.6+ 설치 |
| `.env.local`을 만들어도 지도가 안 뜸 | **개발 서버 재시작.** Vite는 환경변수를 시작할 때 한 번만 읽음 |
| 카카오 도메인 등록에 포트를 빼먹어 지도가 안 뜸 | `http://localhost:5173` 처럼 **포트까지** 등록 |
| **새 앱은 카카오맵 서비스가 꺼져 있다.** 키가 맞고 도메인 등록을 끝내도 지도가 안 뜬다 | `제품 설정 → 카카오맵 → 활성화 설정 ON`. **이것과 도메인 미등록은 화면에서 똑같이 보인다** — `curl.exe`로 카카오 응답을 직접 받아 구별한다 (README 4-3) |
| 카카오 콘솔 메뉴가 바뀌어 README와 다름 | 도메인 등록은 이제 `플랫폼 키 → JavaScript 키 수정 → JavaScript SDK 도메인`. 또 바뀔 수 있으니 **이름이 아니라 기능으로** 찾을 것 |
| **엑셀로 받은 좌표 두 줄이 소수점까지 똑같았다** | 복사 붙여넣기 사고. 지도에서 핀이 완전히 겹쳐 한 곳으로 보인다. 좌표를 새로 받으면 **가까운 쌍이 있는지 먼저 훑을 것** |
| **바텀시트가 떴다가 지도에 덮임** | 카카오가 지도 안에 `z-index: 1~2` 레이어를 만드는데, 래퍼가 쌓임 맥락을 안 만들면 그 값이 밖으로 새어나온다. `KakaoMapView` 래퍼의 `isolate`가 이걸 가둔다. **지우지 말 것** |
| **바가 한 곳만 남으면 지도가 과확대됨** | `setBounds`가 한 점으로 접혀 축척 30m까지 당겨진다. `CLOSEST_LEVEL = 4`로 상한을 뒀다 |
| PowerShell here-string(`@'...'@`)을 Bash에서 써서 커밋 메시지에 `@`가 섞임 | Bash에서는 heredoc(`<<'EOF'`)을 쓸 것 |
| `pip`과 `python`이 서로 다른 인터프리터를 가리킴 (엑셀 읽을 때) | `pip install`이 되는데 `import`가 안 되면 인터프리터 경로를 직접 지정 |
| PowerShell에서 `curl`이 다른 명령의 별칭이라 API 테스트 실패 | Git Bash를 쓰거나 `curl.exe`로 호출 |
| `npm install`이 매우 느림 (수 분) | USB/FAT32에서 작업하면 정상. `node_modules`가 작은 파일 1만 2천여 개다. 백그라운드로 돌리고 기다리거나, 내장 드라이브로 옮길 것 (2절 참고) |

## 8. `board-api/`는 이 앱과 무관합니다

백엔드 학습용 **연습 프로젝트**입니다. 저장소만 같이 쓸 뿐 앱은 이 서버를 호출하지 않습니다.
서버가 죽어도 앱은 멀쩡합니다.

1단계(메모리 배열 CRUD) 골격만 있고 `GET /posts` 하나만 구현돼 있습니다.
나머지는 **학습자가 직접 채울 TODO 스텁**이니 **대신 구현해주지 마세요.**
힌트와 질문만 남겨둔 상태입니다. 자세한 내용은 `board-api/README.md`.

**4단계(인증)를 끝내기 전에는 이 서버를 앱에 연결하지 않습니다.**
